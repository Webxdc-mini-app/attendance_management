# 出退勤管理 v2.1.0

Delta Chatのチャット内で、出勤・休憩・退勤を記録するwebxdcミニアプリです。本人による記録修正、月次集計、CSV出力、代表によるメンバー管理、15言語の表示切り替えに対応しています。

配布ファイル：`attendance_management_v2.1.0.xdc`

## 主な機能

- 出勤・退勤、休憩の開始・終了を記録。休憩は1日に複数回登録できます。
- 日付ごとに時刻、休憩、勤務区分、メモを編集できます。
- 勤務区分は「勤務」「休日」「欠勤」「有給」「未設定」から選べます。
- 出勤日数、総労働時間、総休憩時間、平均実働時間を月ごとに表示します。
- 自分の記録をCSVで出力できます。
- 代表は、全員の状況確認・記録修正・月次集計・CSV出力ができます。
- 言語は各端末で選択でき、異なる言語の参加者が同じ記録を共有できます。

## 利用環境と導入

webxdcを利用できるDelta Chatが必要です。アプリ専用のアカウント登録や専用サーバーの設置は不要です。画面の配置やファイル保存の操作は端末によって異なります。

1. 勤怠を共有するDelta Chatのチャットを開きます。
2. `attendance_management_v2.1.0.xdc`を添付ファイルとして送信します。
3. 参加者はそのメッセージからアプリを起動します。起動ボタンは「開始」「Start」などと表示されます。
4. 同期が終わってから、画面上部で氏名・日付・言語を確認します。
5. 代表となる担当者が、必要に応じて「代表になる」を押します。

**毎回、同じチャット内の同じアプリのメッセージを開いてください。** 同じXDCファイルを別のメッセージとして送信した場合、それぞれ別のアプリとして扱われます。

## 毎日の操作

```text
仕事を始める → 出勤
休憩を始める → 休憩入
仕事に戻る   → 休憩戻
仕事を終える → 退勤
```

打刻には、操作した端末の現在時刻が使われます。打刻後は表示された時刻と状態を確認してください。

「今日のメモ」は、入力を止めて約0.8秒後、または入力欄から離れたときに自動保存されます。編集画面で変更したメモは「保存」が必要です。

### 打刻忘れや間違いの修正

1. 今日の記録は「編集」、過去の記録は「月次記録」の対象日を押します。
2. 出勤・退勤時刻、休憩、勤務区分、メモを修正します。
3. 対象者と日付を確認して「保存」を押します。

「＋ 休憩を追加」では、初期値として12:00～13:00が入ります。実際の時刻に直してください。休憩行の「×」で、その休憩を取り除けます。「キャンセル」や画面上部の「×」では変更を保存しません。

退勤を早く押した場合は「取り消して再編集」で退勤時刻を取り消せます。この操作だけでは編集画面は開きません。必要な修正を行い、勤務終了時に改めて「退勤」を押します。

### 休日・欠勤・有給の登録

対象日を編集して勤務区分を選び、「保存」を押します。勤務しない日は通常、出勤・退勤時刻を空欄にします。**勤務区分を変えるだけでは、登録済みの時刻は消えません。**

## 月次集計とCSV出力

「月次記録」の左右の矢印で対象月を選びます。

| 集計項目 | 内容 |
| --- | --- |
| 出勤日数 | 出勤時刻がある日の日数 |
| 総労働 | 月内の実働時間の合計 |
| 総休憩 | 出勤時刻がある日の休憩時間の合計 |
| 平均 | 総労働時間を出勤日数で割り、分単位に丸めた時間 |

実働時間は「退勤時刻 − 出勤時刻 − 休憩時間」で計算します。例えば09:00～18:00、休憩12:00～13:00なら、実働は08:00です。

今日の画面では勤務中の経過時間も表示しますが、月次集計とCSVでは、退勤時刻が未入力の日の実働は0になります。出勤時刻があれば、その日は出勤日数に含まれます。有給のみで出勤時刻がない日は含まれません。

### CSVの出力範囲

| 操作場所 | 出力される記録 |
| --- | --- |
| 自分の「月次記録」→「CSV出力」 | 表示月の自分の記録 |
| 代表の「状況」→「CSV出力」 | 選んだ日を含む月の全員分 |
| 代表の「月次集計」→「全員CSV出力」 | 表示月の全員分 |
| 代表が開いた個人の月次画面→「CSV出力」 | 表示月のその人の記録 |

CSVは対象月の全日分を含みます。基本の列は、日付・曜日・ステータス・出勤・退勤・休憩（分）・実働（分）・実働（時間）・メモです。代表が出力するCSVには、メンバー名とアドレスも付きます。

- 文字コードはUTF-8（BOM付き）です。
- 見出し、曜日、表示用のステータスは、出力時の選択言語になります。
- 日付は`YYYY-MM-DD`、時刻は`HH:MM`で出力します。
- 実働（時間）は小数です。7時間30分は`7.50`になります。
- 氏名とメモは入力されたまま出力します。
- ファイルの保存場所や開き方は、端末の案内に従ってください。
- **CSVの取り込み機能はありません。CSVからアプリの記録を復元することはできません。**

## 代表によるメンバー管理

代表は1人です。未設定の場合に「代表になる」を押すと、「自分の打刻」と「メンバー管理」の切り替えが表示されます。代表未設定でも、本人の打刻は利用できます。

| 画面 | 用途 |
| --- | --- |
| 状況 | 日付を選び、全員の勤務状況を確認。行を押して当日の記録を修正 |
| 月次集計 | 全員の月次集計を確認。行を押して個人の日別記録を確認・修正 |
| 打刻ログ | 出勤、退勤、休憩、退勤取消、記録修正の履歴を確認 |

メンバーは同じアプリを開くと、自動で一覧に追加されます。代表が他のメンバーの記録を修正すると、その旨が打刻ログに残ります。本人も自分の記録を修正できます。

打刻ログは新しい順に最大300件表示され、メンバーで絞り込めます。メモだけの自動保存は、打刻ログには表示されません。

### 代表の移譲と解除

「状況」画面の下部にある「代表の設定」で操作します。

- **移譲**：相手を選択して「移譲」を押します。相手は、先に同じアプリを開いて一覧に登録されている必要があります。
- **解除**：「代表を解除」を押すと未設定に戻ります。次の担当者が「代表になる」を押せます。

移譲と解除には確認画面がありません。操作後は、担当者と管理画面の表示を確認してください。

| ar | アラビア語 | العربية |
| de | ドイツ語 | Deutsch |
| en | 英語 | English |
| es | スペイン語 | Español |
| fil | フィリピノ語 | Filipino |
| fr | フランス語 | Français |
| id | インドネシア語 | Bahasa Indonesia |
| jp | 日本語 | 日本語 |
| ko | 韓国語 | 한국어 |
| ne | ネパール語 | नेपाली |
| pt | ポルトガル語 | Português |
| ru | ロシア語 | Русский |
| ti | ティグリニャ語 | ትግርኛ |
| vi | ベトナム語 | Tiếng Việt |
| zh | 中国語 簡体字 | 中文 简体 |

初回は端末の言語設定を参照し、対応する言語がなければ英語で表示します。画面上部の選択欄で変更できます。

- 言語設定は端末側に保存し、他の参加者の表示言語には影響しません。
- 端末側の保存が許可されない環境では、再起動後に選択を保持できない場合があります。
- アラビア語では画面を右から左に表示します。
- 日本語の選択コードは`jp`、HTMLの言語指定と日付表示では標準コードの`ja`を使います。
- 日付表示はグレゴリオ暦を使用します。
- 氏名やメモの内容は自動翻訳しません。
- 翻訳辞書をアプリ内に含むため、外部翻訳サービスは使用しません。

## データ共有と削除

勤怠記録は、このアプリを共有するチャット参加者の端末へ同期されます。通信状況によって、相手の画面への反映が遅れる場合があります。同じ日の記録を同時に修正することは避け、修正後の内容を確認してください。

**管理画面を代表だけに表示することと、データの配布先を代表だけに限定することは異なります。** このアプリのデータはチャット参加者に共有されるため、メモには共有してよい内容だけを入力してください。

「月次記録」→「全削除」→「削除する」で、自分の勤怠記録と打刻ログを削除できます。

- 対象は表示月だけではなく、**自分の全期間の記録**です。
- 同期後は代表側の表示からも消えます。他人の記録は消えません。
- アプリ内で元に戻す機能はありません。
- 出力済みのCSVなど、アプリ外のコピーを削除する操作ではありません。

## 旧版からの切り替え

**新しいXDCファイルをチャットに送信しても、旧版の別メッセージにある記録は自動では移行されません。**

1. 旧版で必要な月のCSVを出力します。
2. 旧版のアプリのメッセージを残します。
3. 新版を送信し、全員が同じ新版のメッセージを開きます。
4. 新版で記録を始める日を決め、旧版との二重入力を避けます。

v2.0.0と勤怠データのイベント形式`v2`を共通にしていますが、これは別メッセージ間でのデータ移行を意味しません。旧v1の端末内データを取り込む処理も残っていますが、新版から旧メッセージの保存領域を読み出す機能ではありません。

## 制限と運用上の注意

- **日をまたぐ勤務には対応していません。** 22:00出勤・翌日06:00退勤などは正しく計算できません。
- 出勤・退勤・休憩の前後関係、休憩の重複、勤務時間外の休憩は、自分で確認する必要があります。
- 端末の時計を使用します。参加者の端末の日時を正しく設定してください。
- 休日や有給を自動で判定しません。勤務区分は手動で登録します。
- 給与、残業代、有給時間の自動計算機能はありません。
- 承認、月締め、編集ロックの機能はありません。確定した記録として扱う場合は、担当者が確認してCSVを保存するなどの手順を設けてください。
- アプリを閉じている間の自動通知や、打刻忘れを通知する機能はありません。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 同期中と表示されて操作できない | 少し待って再操作し、通信状況を確認する |
| メンバーが一覧にいない | 相手が同じアプリのメッセージを開いたか確認する |
| 管理画面が表示されない | 自分が代表になっているか確認する |
| 月次の実働時間が0 | 出勤・退勤が両方入力され、時刻の順序が正しいか確認する |
| CSVが見つからない | 端末のダウンロードや保存先を確認する |
| 参加者ごとに記録が違う | 同じアプリのメッセージか、通信後に同期されるか確認する |
| 言語を変えてもメモが変わらない | 入力された氏名やメモは翻訳しない仕様 |

## ファイル構成

XDCはZIP形式のパッケージです。内容は次の4ファイルです。

```text
attendance_management_v2.1.0.xdc
├── index.html       画面、打刻、集計、同期、CSV処理
├── i18n.js          15言語の翻訳辞書、言語設定、日付表示
├── manifest.toml    アプリ情報とバージョン
└── icon.png         アプリアイコン
```

再パッケージする場合は、4ファイルをZIPの直下に格納し、拡張子を`.xdc`にします。親フォルダーをZIPに含めないでください。`webxdc.js`はDelta Chatが提供するため、パッケージには含めません。

## 検証範囲

15言語対応版の開発時に、単体ブラウザで基本の打刻・編集・CSV内容の生成・管理画面・言語設定の保持を確認しました。模擬webxdc通信では、異なる言語間の同期、旧v2.0.0とのイベント互換、代表の移譲・解除、削除の同期などを確認しました。

Delta Chat実機での通信およびCSV保存操作は未確認です。各言語の訳文は、専門の翻訳者による校閲は行っていません。
